# 3D Printing Cost Calculator

Uma ferramenta simples e eficiente para calcular o custo total das suas impressões 3D. 

🚀 **Acesse a calculadora online:** [Github Pages](https://vitordm.github.io/3d-printing-cost-calculator/)

## 🚀 Sobre
Este projeto foi desenvolvido para ajudar entusiastas e profissionais da impressão 3D a precificar seus serviços ou entender o custo real de suas peças impressas, levando em consideração materiais, energia e outros fatores variáveis.

## 🛠️ Funcionalidades
- [x] **Cálculo de Consumo de Filamento:** Baseado no peso (g) da peça final.
- [x] **Estimativa de Custo de Energia:** Baseado no tempo de impressão e consumo da impressora.
- [x] **Configuração de Margem:** Defina sua margem de lucro e custos operacionais.
- [x] **Interface Intuitiva:** Cálculos rápidos e fáceis de usar.

## 💻 Como utilizar
1. **Online:** Acesse [Github Pages](https://vitordm.github.io/3d-printing-cost-calculator/) diretamente pelo seu navegador.
2. **Localmente:**
   - Clone o repositório:
     `git clone https://github.com/vitordm/3d-printing-cost-calculator.git`
   - Abra o arquivo `index.html` no seu navegador.
   - Insira os dados da sua impressão nos campos solicitados.
   - Obtenha o resultado do custo final instantaneamente.
