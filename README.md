# 3D Printing Cost Calculator

Uma ferramenta simples e eficiente para calcular o custo total das suas impressões 3D. 

## 🚀 Sobre
Este projeto foi desenvolvido para ajudar entusiastas e profissionais da impressão 3D a precificar seus serviços ou entender o custo real de suas peças impressas, levando em consideração materiais, energia e outros fatores variáveis.

## 🛠️ Funcionalidades
- [v] **Cálculo de Consumo de Filamento:** Baseado no peso (g) da peça final.
- [v] **Estimativa de Custo de Energia:** Baseado no tempo de impressão e consumo da impressora.
- [v] **Configuração de Margem:** Defina sua margem de lucro e custos operacionais.
- [v] **Interface Intuitiva:** Cálculos rápidos e fáceis de usar.

## 💻 Como utilizar
1. Clone o repositório:
   `git clone https://github.com/vitordm/3d-printing-cost-calculator.git`
2. Abra o arquivo index.html no seu navegador.
3. Insira os dados da sua impressão nos campos solicitados.
4. Obtenha o resultado do custo final instantaneamente.
